# Archived Datasets

These experiments are retained for reference and possible restoration. The active app, offline cache, scheduled data updates, and README videos exclude them.

- [ENSO](enso/README.md): monthly relative Nino 3.4 index, parser, snapshot, updater, tests, and former browser integration.
- [Sea ice models](sea-ice-models/README.md): GIOMAS and ORAS5 processing, snapshots, tests, and workflow templates.

Each archive documents its optional checks and restoration steps. Running an archived updater does not enable its dataset in the app.
